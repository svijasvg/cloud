### Pwika: web sites with SVG instead of HTML

This is the server component of a suite of open-source programs that enable the creation of rich web content with Adobe Illustrator.

You can use Pwika for free without building your own server: see [pwika.com](https://pwika.com)

For more information about how to use this repository, please visit our main Github page: [github.com/pwikasvg](https://github.com/pwikasvg)

![](images/divider.jpg "————————————————————————————————————————")

### Description

Pwika Cloud is a Django program that serves SVG files in the form of a website.

![](images/divider.jpg "————————————————————————————————————————")

### Hosting

We use [Linode/Akamai](https://cloud.linode.com) for our hosts. All the instructions you'll find in our repositories reflect this.

![](images/divider.jpg "————————————————————————————————————————")

### Requirements

Pwika Cloud expects a server with a specific virtual environment installed.

To install Pwika Cloud, please first set up a server according to the [Pwika Server repository](https://github.com/pwikasvg/server).

![](images/divider.jpg "————————————————————————————————————————")

### Updating

To update to a new version of Pwika Cloud, refer to the [Cloud Update](https://github.com/pwikasvg/cloud-update) repository.
